CRADOS

BROWSER-NATIVE EXPERIMENT

把浏览器当作运行平台。

CRADOS 是一个基于浏览器 JavaScript 引擎的轻量实验。应用运行在沙箱 iframe 中，通过权限代理访问受控系统服务。

执行环境

JavaScript

浏览器原生引擎

隔离方式

Sandbox iframe

独立的 guest 页面

虚拟文件

0 个文件

保存在当前浏览器

设计原则

应用与宿主分离

Guest 代码不直接访问 OS 主页面的 DOM。

显式权限

网络和文件操作必须经过宿主权限检查。

静态部署

无需构建工具、服务端或额外依赖。

明确安全边界

这是浏览器实验，不是经过安全认证的操作系统。

EXECUTION

JavaScript 运行环境

使用 Ctrl/⌘ + Enter 运行。网络权限默认关闭。

Guest 页面

系统控制台

内核就绪，等待执行。

Guest 脚本仍可能占用 CPU 和内存。启用网络后，请求仍受浏览器 CORS 和混合内容策略限制。

SECURITY

权限管理

权限保存在当前浏览器中。宿主会在每次调用时重新检查授权。

这是原型权限界面，不构成安全认证。正式使用还需要威胁模型、严格的 RPC 校验、资源限制和浏览器测试。

LOCAL STORAGE

虚拟文件

文件保存在当前浏览器的 IndexedDB 中，不会主动上传。

浏览器或用户可能清除本地数据。不要在这里保存机密信息。

ARCHITECTURE

系统架构

CRADOS Shell可信 UI
Permission Broker权限检查与 RPC
Sandboxed Guest不可信 JavaScript
Browser Engine执行环境与 Web API
IndexedDB本地虚拟文件
