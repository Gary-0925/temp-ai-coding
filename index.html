快速开始

  1. 在「运行环境」中编写 JavaScript 并运行。
  2. 需要保存代码时，使用「保存到文件」。
  3. 网络请求和虚拟文件 API 默认需要在「权限」中授权。

这是实验性原型。沙箱不能阻止无限循环造成的 CPU 占用，不要运行不可信的长时间任务。
