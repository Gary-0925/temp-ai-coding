Kernel principles

DESIGN NOTES
01 / Guest ≠ Host

Guest code cannot directly access the host page's DOM or JavaScript realm.

02 / Capabilities, not globals

Privileged operations cross a checked message bridge.

03 / Static-first

No backend or build system is required for this MVP.

04 / Honest boundaries

A browser sandbox is useful isolation, not a hardened OS security boundary.

USERLAND / EXECUTION

JavaScript Runtime

Edit JavaScript, then run it inside a sandboxed iframe. Press Ctrl/⌘ + Enter to run.

Scripts can still consume CPU and memory. Network access is off by default; browser CORS and mixed-content restrictions still apply when enabled.

SECURITY / CAPABILITIES

Permission Center

Grants are stored in this browser only. Each operation is checked again by the host.

This is a prototype permission UI, not a security certification. Production needs a threat model, strict RPC schema validation, timeouts, resource limits, and browser integration tests.
VFS / LOCAL PERSISTENCE

Virtual Files

Files are saved in IndexedDB in this browser profile and are never uploaded.

Browser storage can be cleared by you or by browser policy. Do not store secrets here.

PROJECT / CRADOS

Not another fake terminal.

Treat the browser as the execution substrate, then build a capability-controlled OS around it.
